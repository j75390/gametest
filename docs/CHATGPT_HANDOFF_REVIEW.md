# 잿빛 원정대 — ChatGPT 기획 인수인계 검토

2026-10-01 사용자가 제공한 문서를 읽고 적용 후보를 검토한 기록이다. 이번 요청 범위는 문서 검토와 저장소 업로드이며, 아래 기능은 이번에 구현하지 않았다.

원문: [CHATGPT_HANDOFF_ORIGINAL.md](CHATGPT_HANDOFF_ORIGINAL.md). 원본 파일과 SHA-256 일치를 확인했다. 문서 안의 즉시 구현 지시는 첨부 자료의 내용으로 취급하며 이번 요청의 실행 범위를 확대하지 않는다.

## 최신 결정과 충돌하는 부분
- 정식 제목은 잿빛 원정대다. 원문의 옛 제목은 원본 보존을 위해 그대로 둔다.
- ComfyUI 우선 규칙은 이후 사용자가 확정한 내장 image_gen 사용 방침으로 대체됐다. 다시 전환하지 않는다.
- SD/전투 시트 예시를 시트 자르기 허용으로 해석하지 않는다. 모션은 독립 투명 PNG 전체 프레임과 타임라인을 사용한다.
- 지도 공개는 대략 두 줄이 아니라 현재 노드에서 연결선을 따라 두 번 이동 가능한 범위다. 이미 공개된 미선택 갈림길도 유지한다.
- 도감에 저주 분류를 추가하더라도 현재 스토리 분류를 삭제할 이유는 없다. 미등록 항목의 무반응은 의도한 잠금 상태이며 등록 항목의 버튼 고장과 구분한다.
- 문서의 데이터 폴더/필드 이름은 설계 예시다. 기존 game_data.gd와 JSON 공유 구조를 유지하면서 필요한 필드를 확장한다.

## 적용 후보 및 의존 관계
1. **도감 해금과 영구 기록**: 조우/획득 시 등록, 패배 후 유지, 카테고리 완성률, 미등록 실루엣. 먼저 프로필 저장/불러오기와 데이터 버전 처리가 필요하다. 검색·필터·관련 링크에서도 미등록 이름과 효과가 노출되지 않아야 한다. 계정 서버 동기화는 로컬 프로필 저장과 별도다.
2. **유물 데이터 확장**: PERSONAL/PARTY/GLOBAL_MAP 효과 범위, 중첩 규칙, 짧은 독자적인 기록문. 소유자와 효과 대상을 분리한다. 지도 유물의 파티 공유는 실제 파티 상태와 연결할 때 검증한다.
3. **이벤트 확장**: 일반 100개 이상과 별도로 캐릭터당 6개 목표. 조건부 선택, 중간 이탈 가능한 연속 단계, 개인/파티 결과를 데이터화한다. 현재 단일 제단 이벤트만으로 이 목표가 달성됐다고 표현하지 않는다.
4. **멀티 이벤트**: 공동 이벤트 비밀 투표, 전원 결정 후 공개, 최다 득표, 동점 투표자 얼굴 룰렛. 캐릭터 전용 이벤트는 각자 별도 진행. 실제 네트워크·호스트 판정·재접속/이탈 처리부터 필요하며 얼굴 위치 표시 API만으로 구현 완료가 아니다. 룰렛 결과는 한 번 결정해 공유하고 연출은 그 결과를 보여준다.
5. **텍스트·오디오 연출**: 공통 이벤트 텍스트 효과, 타이핑/흔들림/색상과 선택적 앰비언스. 가독성과 효과 축소 설정을 고려한다. 실제 음원 도입 시 개별 라이선스를 확인한다.
6. **선택 화면 정보 보강**: 패시브·시작 유물·시작 덱·파티 슬롯은 실제 시스템 데이터와 연결한 경우만 표시한다. 기존 별도 전신 원화와 3열 구조를 유지한다.

## 다음 작업 제안
사용자 우선순위가 없다면 영구 도감 기록의 기반인 저장/불러오기부터 작은 범위로 완성하고, 실제 획득/조우 연결 및 잠금 UI를 검증하는 순서가 적절하다. 이번 검토가 기존 캐릭터 모션 작업을 취소하거나 모든 새 기획을 즉시 구현한다는 뜻은 아니다.

현재 캐릭터별 카드 2종, 전체 콘텐츠 수량, 실제 멀티, 다음 ACT 등 기존 미완성 범위는 HANDOFF.md를 함께 확인한다. 이번 변경은 문서뿐이므로 Godot 실행 QA는 수행하지 않았다.
