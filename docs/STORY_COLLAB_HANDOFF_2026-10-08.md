# 스토리 방향 인수인계 — Codex → Claude

2026-10-08. 사용자가 그동안 이야기한 집필 방식과 화면 형태를 Claude에게 인수인계하도록 요청했다. 이 문서는 기존 서사 자료의 핵심을 연결하며, 새로운 세계관을 확정하거나 후반 구현을 완료했다고 선언하지 않는다.

## 1. 사용자가 요청한 방향

- 우선 범위는 **지역 이야기, 미라 서사 여러 편, 미라 관련 유물 기록**이다. 다른 캐릭터 전체 서사를 먼저 늘리지 않는다.
- 슬더스2처럼 원정을 통해 기록이 열리고, 작은 이야기들이 이어져 인물과 세계를 이해하는 구조를 참고한다. 문구·캐릭터·설정을 복제하지 않는다.
- 로보토미를 떠올리게 하는 약간의 불길함을 원했다. 평범한 업무 기록과 실제 상황이 어긋나는 느낌으로 표현한다. 잔혹함이나 난해한 설정을 계속 늘리는 방식으로 해석하지 않는다.
- 지역은 이름과 설명만 붙이지 않는다. 땅의 형태, 고도, 물길, 사람들이 살던 이유, 시설의 연결, 원정 진입과 출구를 차근차근 정리한다.
- 작은 비밀에도 궁금증이 생겨야 한다. 처음에는 사소한 흔적으로 보이고, 다른 기록과 대조하면 의미가 달라지는 단서를 배치한다.
- 스토리 그림은 작은 캐릭터 초상 칸을 반복하지 않는다. 이야기 속 실제 장소·물건·행동에 맞는 장면 삽화를 크게 보여 준다.

## 2. 확정 방향과 작가용 초안을 구분

미라라는 이름, 연금술사, 머리 옆 위에 걸친 까마귀 부리형 역병의사 가면, 이안이 가면 안쪽에 미라의 이름을 남긴 방향은 진행 승인된 설정이다. 이름은 물리적인 글씨이며 부활 주문이 아니다. 이름을 읽으면 모든 기억이 즉시 돌아오는 식으로 쓰지 않는다.

성화·흰 막·고통 전달 제도, 다섯 지역의 시설 기능, 후반 선택과 결말의 상세는 STORY_BIBLE_DRAFT.md와 REGION_ATLAS.md의 **작가용 초안**이다. 이미 전부 사용자 확정 또는 게임 구현된 것으로 취급하지 않는다. 초기 플레이어 문구에 작가용 진실을 복사하지 않는다.

## 3. 어떻게 쓸 것인가

기록 한 편은 하나의 장면과 하나의 의문에 집중한다. 권장 흐름은 다음과 같다.

1. 구체적인 생활 흔적: 닳은 손잡이, 접힌 담요, 날짜, 도장, 물때, 다른 필체.
2. 인물의 확인 행동: 펼친다, 재본다, 두 종이를 겹친다, 담당자에게 묻는다.
3. 작은 어긋남: 빈 침대의 오늘 확인 도장, 손을 떼어도 기우는 저울, 질문받지 않은 사람의 빈칸.
4. 짧은 반응 또는 대사. 세계관 강의로 장면을 끊지 않는다.
5. 단서를 남기되 정답은 공개 단계에 맞춰 제한한다. 일부 이야기는 생활이나 기다림으로 끝나도 된다.

권장 분량은 짧은 기록 2~4문단, 중요한 대조 장면은 필요할 만큼 확장한다. 이는 편집 기준 제안이지 사용자 확정 글자 수가 아니다. 제목·장소·기록 종류·작성자/시점이 있으면 독자가 관측과 해석을 구분하기 쉽다.

피할 것: 모든 물건이 저주받았다는 결론, 매번 의미심장한 마지막 한 줄, 같은 초승달/이름 표현의 반복, 미라의 장황한 독백, 불명확함을 이유로 인과를 설명하지 않는 결말. 실제로 환자를 살린 약과 따뜻한 생활도 남긴다. 지켜야 할 것이 보여야 손실이 무겁다.

## 4. 미라의 공개 순서

| 단계 | 플레이어에게 보이는 사실 | 아직 숨기는 것 |
|---|---|---|
| 선택 화면 | 지워진 이름과 치료했던 사람들의 흔적을 찾는다 | 이안과 고통 전달의 진실 |
| 서문 | 가면 안쪽 이름은 미라 자신의 필체가 아니다 | 누가 왜 적었는지 |
| ACT I 병동 | 치료 기록의 필체와 가면 필체가 다르다. 미라의 과거 업무와 책임의 흔적 | 이안의 행동을 정답으로 설명하지 않음 |
| ACT III 온실 초안 | 공동 서명의 획이 가면 글씨와 닮았다 | 단순 유사성만으로 작성자 확정 금지 |
| ACT IV 서고 초안 | 편지·원본·가면을 대조해 이안의 행동을 확인 | 앞 단계에 편지 전문 노출 금지 |
| 후반 결말 초안 | 미라가 자신의 이름으로 직접 서명하고 앞으로의 책임을 선택 | 강제 개명·자동 기억 회복 금지 |

미라의 핵심은 기억 찾기에만 있지 않다. 치료가 실제 도움을 주었지만 누군가에게 대가를 떠넘긴 절차에 참여했던 책임을 마주한다. 돌려받을 사람의 동의, 멈출 권리, 돌아온 뒤의 돌봄을 함께 다룬다. 이안은 이를 단순히 대신 해결해 주는 구원자로 쓰지 않는다.

## 5. 지역은 지도와 기록을 함께 설계

큰 지형안은 남쪽이 열린 내륙 분지다. 북쪽 능선과 동서 산지가 둘러싸고 물길은 남쪽 마을로 이어진다. 위치·경로 상세는 REGION_ATLAS.md를 우선한다.

| 지역 | 땅과 진행 골격 | 작은 비밀의 예 | 공개/구현 상태 |
|---|---|---|---|
| 잿빛 성당 | 서쪽 언덕, 입구·접수·병동·약제 회랑·안뜰·북쪽 문 | 빈 침상 도장, 명패 뒷면, 꿰맨 장부 표지 | ACT I 진행 및 일부 조사 연결 |
| 검은 운하 | 중앙 저지대 수로, 검사소·수송선/둑길·우회 수문·동쪽 하역장 | 비어 보이는 배의 깊은 흘수선 | 후반 원고·지역 설계, 실제 진행 미구현 |
| 유리 온실 | 동쪽 높은 단구, 양수관·하역 승강기·재배동·정제/폐기·배합 기록 | 환기 기록의 빈칸, 이름표 끝 글자의 다른 획 | 후반 원고·설계 |
| 이름 없는 서고 | 북서 암반, 건식 회랑·색인실·복구대·삭제관·편지 대조 | 책보다 한 장 많은 반납표 | 후반 원고·설계 |
| 새벽 없는 성소 | 북쪽 절벽의 분배 시설, 대기소·외곽·정지·처리/귀환 | 쉬는 박자 대신 적힌 배정 번호 | 후반 원고·설계 |

지도는 사용자 참고처럼 산·숲·강·도로·건물로 땅의 형태가 읽히는 판타지 삽화 지도다. 흐름도 박스와 화살표로 대체하지 않는다. 전체 지형 그림과 실제 전투 노드 지도는 별도 역할이다. 성당 조사 지도는 도착/진행에 따라 조사 지점이 열리고 기록과 연결된다.

큰 지도는 충분히 크게 보고 확대/스크롤할 수 있게 해야 한다. 이전 지역 도감의 작은 지도 표시를 사용자가 거절했다. 작은 썸네일 가운데 놓고 설명만 길게 붙이는 형태로 되돌리지 않는다. 후반 지역을 플레이어에게 한꺼번에 공개하거나 조사만으로 핵심 진실을 모두 보여 주지 않는다.

비밀 관리 항목: 처음 보이는 흔적 / 추가 확인 행동 / 연결 기록 / 회수 시점 / 놓쳐도 되는가 / 공개 조건. 필수 이야기 이해가 선택 단서 하나를 놓쳤다고 불가능해지지 않게 한다. 물이 역류하거나 시설이 이동한다면 실제 원인과 공간 규칙을 유지한다.

## 6. 유물 이야기의 형태

유물은 짧은 기능 설명과 별도의 기록문을 구분한다. 기록문은 물건을 쓴 사람, 닳거나 수선된 부분, 남은 문서로 시작한다. 기능 수치가 곧 세계관 진실이라는 식으로 쓰지 않는다. 초승달만 반복 제작하지 않고 골무·집게·심지·담요·주머니·처방판·공동 서명 처방전 등 각 물건의 역할을 살린다.

미라 시작 유물 빛바랜 초승달의 기존 방어3 효과는 서사 개정과 별개로 유지한다. 가면 이름과 초승달은 서로 다른 증거/행동이다. 이름을 남긴 행동과 고통 일부를 대신 받은 행동을 한 가지 마법으로 합치지 않는다.

뒤 단계 유물의 기록은 병동 장부·공동 서명·편지 등의 공개 조건을 따른다. 유물을 발견했다는 이유만으로 이안의 모든 사실이 풀리지 않게 한다. 효과가 원고인 유물은 전투 구현 완료로 표시하지 않는다.

## 7. 도감·스토리·연대표 화면 역할

**일반 도감:** 사용자가 명확히 보상 내용과 획득/해금 조건 노출을 거절했다. 유물·포션 미발견 상태는 형태의 실루엣과 ‘아직 이 유물을 발견하지 못했습니다’ 같은 안내만. 이름·설명·검색/필터로 비밀이 새지 않아야 한다. 수집품은 넓은 그리드와 hover 설명이며 모든 종류를 상시 상세/모션/갤러리 한 화면에 몰아넣지 않는다.

**스토리 읽기:** 기록 목록에서 하나 선택 → 제목/장소·기록 종류 → 장면 삽화 → 충분한 폭의 본문. 작은 캐릭터 사진 옆에 긴 텍스트를 붙이는 옛 형태는 거절됐다. 본문 스크롤, 글자 잘림과 줄바꿈, 1280/1440에서 삽화가 실제로 보이는 크기 검수. 각 기록에 관계있는 물건·장소·행동을 그린다.

**연대표:** 사용자가 보여 준 예시는 가로 시간축의 사건 묶음, 잠금/해금 상태, 선택한 사건의 큰 삽화·짧은 이야기·다음/이전 보기, 진행에 따른 카드 해금이다. 이 방향은 구현 목표다. 현재 일반 도감에 해금 보상을 붙여 연대표를 대신하지 않는다. 시간축 정렬은 기록을 얻은 순서와 이야기 속 사건 시점 중 무엇인지 명시한다. 아직 코드 구조가 확정되지 않았다.

연대표 해금조건/보상 표시는 참고 이미지에 있었으나, 사용자가 이후 일반 도감의 보상을 명확히 거절했다. 따라서 조건·카드 보상은 연대표 전용 화면에서의 표시 정책을 정한 뒤 연결한다. 일반 도감과 스토리 본문에는 보상 버튼/수치/획득처를 끼워 넣지 않는다. 실제 카드 해금도 gameplay pool/영구 저장과 연결하기 전에는 완료로 보고하지 않는다.
