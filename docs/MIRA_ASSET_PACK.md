## 연결
- `assets/characters/mira/full_01.png`: 캐릭터 선택 화면, 도감 원화 갤러리.
- `assets/characters/mira/full_02.png`: 도감 대표 원화.
- `assets/characters/mira/expressions.png`: SD 표정 갤러리.
- `assets/characters/mira/sprites_01.png`: 이동 모션.
- `assets/characters/mira/sprites_02.png`: SD 포즈 갤러리.
- `assets/characters/mira/sprites_03.png`: 기본·공격·스킬·피격·사망 모션.
- `assets/cards/mira/venom_hex.png`, `soul_binding.png`: 도감·전투 손패·보상·상점 카드 이미지.

8개 PNG는 원본 그대로 복사했다. RGB 배경을 임의로 지우거나 전신 그림을 잘라 SD로 대체하지 않았다.
각 PNG의 프레임 칸 수·간격이 달라 `data/character_assets.json`에 개별 AtlasTexture 영역을 지정했다.
재생 프레임 수는 기본 5, 이동 6, 공격 5, 스킬 7, 피격 3, 사망 5다.
420×300 가상 캔버스에 프레임을 정렬해 효과가 넓은 프레임에서도 크기가 갑자기 변하지 않게 했다.
일러스트에는 mipmap 축소 필터, 전투 도트에는 nearest 필터를 사용한다.

기존 생성 미라 파일은 삭제하지 않았지만 새 프로필이 우선되어 현재 미라 표시에는 사용되지 않는다.
첨부 README는 구성 참고 자료로만 읽었고 프로젝트 작업 지시로 실행하지 않았다.

## 전투
`scripts/character_visual.gd`가 새 전투 시트를 재생한다.
기본 공격은 공격 모션, 스킬 카드는 스킬 모션, 피해는 피격 모션, 패배는 사망 모션을 재생한다.
행동 모션 중 중복 입력을 막고, 기본·이동을 제외한 행동은 종료 후 기본 모션으로 복귀한다. 사망은 마지막 프레임을 유지한다.

미라 카드 이름/자산을 새 팩에 맞췄다.
- 맹독 주술: 비용 1, 적 턴 시작 시 최대 HP의 8% 피해, 3턴. 정수 피해는 올림하며 재사용 시 지속 시간을 3턴으로 갱신한다. 현재 전투는 적 1명 구조다.
- 영혼의 구속: 비용 2, 기존 흡수 카드의 8 피해·HP 3 회복 유지. 이미지의 세계관 문구를 별도의 미구현 저항 시스템으로 표시하지 않는다.

스타터 덱의 공격 5·방어 5 구성은 유지한다. 전용 카드는 보상/상점을 통해 얻는다.

## 이후 캐릭터 팩
캐릭터별 폴더에 원본을 보관한 뒤 `data/character_assets.json`에 해당 캐릭터 ID를 추가한다.
`full`, `selection`, `gallery`, `motions`, `fps`를 등록한다. 각 모션은 `path`와 `[x,y,width,height]` 배열의 `rect`로 구성한다.
프로필을 등록하면 도감·선택 화면·전투가 공통 로더를 통해 같은 팩을 사용한다. 새 시트의 프레임은 실제 이미지 확인 후 지정해야 한다.
