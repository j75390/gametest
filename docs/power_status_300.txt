운빨원정대 파워 / 버프 / 디버프 / 상태이상 / 저주 / 전용 Power 300개 초안
==========================================================================================

※ 모두 오리지널 초안이며 실제 수치/확률/턴 수는 밸런스 단계에서 확정.
※ 참고작은 구조/가독성 참고용이며 이름·효과·아이콘을 그대로 복제하지 않는다.

중첩 방식
- SINGLE      : 1회 적용/고유 지속형
- COUNTER     : 숫자 중첩형
- DURATION    : 남은 턴 기반
- CONDITIONAL : 조건 만족 중 활성

전투 UI 기준
- 플레이어/몬스터/엘리트/보스 모두 HP바 아래 상태 아이콘 표시
- 아이콘에 중첩 수/남은 턴 표시
- Hover 시 이름/분류/중첩/남은 턴/정확한 효과 설명 표시
