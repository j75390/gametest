# 운빨 원정대 - 프로젝트 제작 규칙

이 프로젝트는 Godot 4.x 기반 다크 고딕 덱빌딩 로그라이크 RPG다.

## 최우선 목표
사용자가 직접 중간 검수하지 않아도 될 정도로
AI가 구현 → 실행 → 오류 확인 → 수정 → 재실행을 반복한다.

임시 구현으로 완료 처리하지 않는다.

## 아트 방향
- 다크 고딕 판타지
- 검정 / 붉은색 / 보라색 / 어두운 금속색 / 탁한 금색
- 성채 / 폐허 / 성당 / 촛불 / 붉은 배너 / 검은 안개
- 웹페이지나 관리툴처럼 보이면 안 된다.
- 게임 UI처럼 보여야 한다.
- 모든 캐릭터/몬스터/UI/카드/배경의 화풍을 통일한다.

references 폴더의 이미지는 미술 방향 참고용이다. 절대 잘라서 게임 자산으로 재사용하지 말고, 새 독립 자산을 제작할 때 스타일 가이드로만 사용한다.

사용자가 제공한 캐릭터 에셋팩의 캐릭터 디자인과 애니메이션풍을 기준으로 한다. 미라를 이전 실사풍으로 되돌리지 않는다. 사용자의 최신 지시에 따라 첨부 스프라이트 시트를 잘라 모션으로 사용하지 않는다. 모션은 같은 캐릭터 디자인을 유지하면서 독립된 투명 배경 프레임으로 새로 제작한다. `data/character_assets.json`에는 전체 프레임 이미지 경로와 재생 시간을 등록한다. 전신 원화를 축소하거나 잘라 SD 모션으로 대체하지 않는다. 이후 제공되는 캐릭터도 이 방식을 따른다.

## 절대 금지
- 한 장짜리 게임 화면 스크린샷을 UI로 사용하는 것
- 투명 클릭 영역만 올리는 것
- 한 이미지에서 캐릭터를 잘라 여러 화면에 재사용하는 것
- 전신 일러스트를 축소해 도트처럼 사용하는 것
- 코드로 그린 저품질 임시 캐릭터
- 텍스트만 있는 카드
- 텍스트만 있는 도감
- 없는 기능을 완료했다고 표시하는 것

## 로컬 ComfyUI 연결 (2026-09-29)
- 설치: D:\Comfy-Desktop. API: http://127.0.0.1:8188. ComfyUI Desktop을 먼저 실행한다.
- 호출: 프로젝트 루트에서 .\ai\comfy_bridge.ps1 status / models / generate 사용. 상세 사용법은 ai/README.md.
- 워크플로: ai/workflows/sdxl_api.json. 현재 설치된 sd_xl_base_1.0.safetensors 사용.
- 생성 결과와 요청/실행 이력은 ai/generated/ 아래 실행별 폴더에 보존한다.
- 그림체 기준 경로는 ai/reference/style/manifest.json. 기본 워크플로에는 LoRA, 이미지 참조 conditioning, 배경 제거가 아직 연결되지 않았다.
- 생성물을 검토한 뒤 assets에 반영하고 기존 data JSON 구조에 등록하여 Godot 실제 실행으로 확인한다. 테스트 결과를 완성 에셋으로 취급하지 않는다.
- 다음 작업: 기존 미라 디자인을 유지하는 참조 기반 워크플로와 투명 배경 처리를 구성하고 미완성 독립 모션을 제작한다.

## 미라 기준 선택 화면 적용 (2026-09-30)
- 사용자 최신 지시: 현재 게임의 미라 원화 느낌(얼굴, 의상, 토끼 가면, 보라색 채색)을 최우선으로 유지한다. 도트/SD와 일러스트, 전용 카드 아트는 각각 필요하며 몬스터도 같은 미술 방향으로 제작한다.
- scripts/character_select.gd에 큰 원화, 정보 패널, 하단 4인 선택 목록, 돌아가기/원정 시작 기능을 구현했다. main.gd의 기존 선택 진입을 연결했고 원정 초기화와 데이터 구조는 유지했다.
- 새 배경: assets/backgrounds/selection_cathedral_v1.png. 로컬 ComfyUI SDXL 생성. 요청과 이력: ai/generated/20260930-000115-92e3a453/. 내장 imagegen은 사용량 한도로 실패했다.
- 미라 일러스트는 기존 assets/characters/mira/full_01.png 전체 이미지를 그대로 표시한다. 새 미라 캐릭터 원화나 새로운 모션이 생성된 것은 아니다. 다른 캐릭터의 기존 원화도 유지한다.
- Godot AI MCP 실제 실행 검증: 미라 표시, 마우스로 칼리안 선택, 원정 시작 시 미라 HP72/덱10장/맵 진입, 선택 오버레이 제거, 돌아가기 시 메인 복귀 성공. 초상화 원본 크기 overflow를 수정하고 재실행했다. run_id r2046855-2 기준 game/editor 오류 없음.
- 현재 난이도 0 표시만 존재한다. 클리어 기반 난이도 해금/저장은 아직 구현하지 않았다. 시작 유물 설명도 실제 지급 로직과 함께 후속 구현할 것.
- 맵 후속 요구: 펼친 고딕 원정 지도 그림 위에 무작위 노드와 연결선, 현재 위치 앞으로 2칸 공개, 나머지 노드/연결선 안개, 이동 시 추가 공개, 지나온 경로 보존. 새 원정마다 랜덤 생성.
- 다음 작업: 기존 캐릭터를 미라 기준 애니메이션풍으로 통일하고 전용 초상화 제작, 실제 클리어와 연동한 난이도 저장, 원정 지도 배경/안개 UI. 이를 완료했다고 표시하지 않는다.

### 선택 화면 배경 수정 (2026-09-30)
사용자가 새 배경과 미라가 맞지 않는다고 지적했다. selection_cathedral_v1.png는 선택 화면에서 더 이상 사용하지 않는다. 기존 미라 원화 자체의 성당 배경을 유지하고 셰이더로 좌우 경계만 어두운 바탕에 연결했다. 얼굴과 의상 위의 전체 암부를 줄여 원본 채색을 보존했다. 원본 이미지 파일은 수정하지 않았다. 화면 배율은 가로세로 동일하게 적용해 다른 창 비율에서도 인물이 찌그러지지 않게 했다. 4인 원화 로드와 1024×768 배율을 Godot AI MCP 실행에서 확인했다. 다른 캐릭터 그림체 통일과 새 독립 아트 제작은 여전히 남아 있다.

- 사용자 수정 지시: 캐릭터 선택 화면에는 카드 이미지·전용 카드 목록·카드 미리보기를 표시하지 않는다. 왼쪽의 허전함은 카드 정보를 추가해서 해결하지 않는다. 2026-09-30 카드 표시 코드를 제거했다.

### ComfyUI 원화 확장 실제 적용 (2026-09-30)
사용자는 ComfyUI로 실제 이미지를 제작해 적용할 것을 명시했다. 미라 full_01.png를 ComfyUI에 업로드하고 왼쪽 640px를 outpaint했다. VAEEncodeForInpaint 첫 시도는 단색이라 폐기하고 VAEEncode + SetLatentNoiseMask로 수정했다. 원본 오른쪽은 마스크 합성으로 보존했다. 결과 assets/characters/mira/selection_panorama_v1.png를 character_assets.json의 selection_panorama로 등록. 카드 미리보기와 임의 원형 장식 제거. 실제 Godot 선택 화면에서 전체 가로형 성당 배경 확인, 에디터 오류 없음. 워크플로 ai/workflows/mira_outpaint_api.json, prompt_id 845a7495-712e-4468-a041-0ec43f777516. 다른 PC에서는 LoadImage 입력 파일을 다시 upload하고 이름을 갱신해야 한다.

- 카드 이미지는 표시하지 않는다. 시작 덱은 실제 공용 공격/방어 각 5장의 텍스트 요약만 표시한다. 미구현 패시브와 유물을 있다고 표시하지 않는다.
- data/character_assets.json의 illustration 경로로 선택 전신을 읽는다. 기존 selection/full/gallery/motions는 보존한다. selection_panorama는 보존하되 선택 화면에서 사용하지 않는다.
- 미라는 기존 배경 포함 원화를 임시로 유지하며 needs_transparent_art=true. UI에서도 준비 중으로 표시한다. 새 투명 전신 제작은 미완료다. 새 illustration 경로로 자동 로드되며 검수 후 needs_transparent_art=false로 바꾼다.
- 칼리안/세라/루시안은 기존 RGBA 전신을 사용하며 투명 채널 확인 완료. 기존 실사풍을 미라의 애니메이션풍으로 통일하는 작업은 아직 남아 있다. 임의로 원화에서 캐릭터를 잘라내지 않았다.
- 독립 배경과 캐릭터 TextureRect 분리, KEEP_ASPECT_CENTERED로 비율 유지. 1440×900에서 4명 실제 마우스 선택 및 스크린샷 확인. 우측 정보 높이 422.625px로 430px 영역 안에 표시되도록 수정.
- 상세정보 팝업, 도감 클릭 후 선택 유지, 원정 시작 시 미라 HP72/덱10장/맵 진입을 실행 검증. 도감에서 선택 전용 프로필을 모션팩으로 오인하던 오류를 has("motions") 검사로 수정. 최종 run_id r4003203-12에서 game 오류 없음.
- 다음 우선 작업: ComfyUI에서 미라 정체성을 유지한 새 선택용 투명 전신 제작 및 검수. 도감용 배경 포함 원화와 용도를 분리. 난이도 해금/저장, 시작 패시브/유물은 미구현 상태 유지.
