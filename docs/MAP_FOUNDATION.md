# 원정 지도 기초 구현 · 2026-09-30

최신 수정: 한 번 공개된 갈림길은 선택하지 않았어도 노드와 연결선을 계속 표시한다. `discovered`와 실제 이동 경로 `visited`를 분리했다. 새롭게 공개되는 범위는 여전히 현재 위치에서 2간선 이내이며 이동은 연결된 다음 노드로만 가능하다. 200개 시드에서 이동 전 공개된 모든 분기가 이동 후에도 유지되는지 검사 통과. 지도 배경과 아이콘의 최신 미술은 MAP_ART_V2.md 및 MAP_ICONS.md를 참조한다.

집에서 수정한 프로젝트는 아직 가져오지 않은 상태에서 학원 프로젝트에 지도 작업만 추가했다. 추후 병합 시 아래 파일을 비교한다.

- `scripts/expedition_map.gd`: 시드 기반 경로 그래프, 현재 위치, 방문 경로, 조우 완료, 2간선 탐색 공개.
- `scripts/map_view.gd`: 실제 노드 버튼, 곡선 연결선, 장소 아이콘, 현재 위치/지나온 길 강조, 안개.
- `scripts/main.gd`: 기존 층별 버튼 목록을 지도 화면으로 교체. 연결된 노드만 진입하고 기존 전투/상점/이벤트/휴식/보물 화면으로 이동. 보스 처리 후 현재 원정 완료 화면.
- `assets/map/`: 프로젝트 전용 SVG 아이콘 8개와 접힌 양피지 배경. 기초 벡터 미술이며 정교한 지도 일러스트/펼치기 애니메이션은 후속 작업.
- `tools/map_qa.gd`: 시드 200개 및 실제 렌더링/입력 검증.

출발점→10개 중간 층→보스. 첫 층은 전투, 보스 직전은 휴식. 상점·보물·엘리트가 그래프에 존재하도록 배치한다. 모든 노드에 도달 경로와 보스까지 이어지는 출구가 있다. 길은 분기/합류하고 같은 층의 경로는 서로 교차하지 않는다. 새 원정은 새 시드를 쓰며 원정 중 화면을 다시 열어도 지도는 바뀌지 않는다.

일반 공개는 현재 노드에서 실제 연결된 길을 2번 따라가 도달 가능한 노드까지이며, 방문 경로는 계속 유지한다. 그 외 노드/연결선/버튼/툴팁은 렌더링하지 않는다. 위쪽의 검은 안개는 불투명하다. 탐험가의 지도 보유 시 현재 지도 전체를 열지만 이동 가능 범위는 바뀌지 않는다.

이번 세션에는 Godot AI MCP 도구가 제공되지 않아 Godot 4.7.2 실행 파일로 직접 검사했다. `--headless --script tools/map_qa.gd`는 그래프, `--script tools/map_qa.gd`는 그래프+실제 창 렌더링+마우스 입력을 검사한다. 200개 시드 재현성/상이성, 고립·막다른 길, 2칸 안개, 중복 이동 금지, 보스 재진입 방지, 클릭→전투→카드→보상→지도, 전체 지도 공개를 검증한다.

실행 환경의 루트 인증서 저장소 경고가 있지만 게임 스크립트 오류와 구분한다. 지도 상태는 현재 메모리에 유지되며 디스크 저장/불러오기는 이 작업 범위에 포함되지 않았다. 다섯 ACT 전체가 완성된 상태가 아니다.

최종 검증: `MAP_GRAPH_QA seeds=200 failures=0`, `MAP_UI_QA failures=0`, 종료 코드 0. 경로 교차 검사와 마우스 휠 스크롤도 포함한다. UI 테스트의 마우스 이동/누름/뗌 순서를 수정한 뒤 통과했다. 기존 main.gd에서 초기 생성 후 덮어쓰던 VBoxContainer 1개를 제거해 종료 시 노드 누수 경고도 해결했다. `docs/map-fog.png`, `map-progress.png`, `map-relic.png`는 Godot 실제 렌더링 결과다.
