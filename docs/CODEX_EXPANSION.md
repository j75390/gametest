# 도감 확장 검사

참고: https://spire-codex.com/kor — 분류와 상세 필드만 참고. 외부 이미지·색상·레이아웃은 가져오지 않는다.

변경 전: 캐릭터/몬스터/유물/지역/스토리 5분류. 카드 독립 목록 없음. 포션/인챈트/이벤트/파워 데이터 없음. 몬스터·이벤트는 화면/전투 코드에 상수로 중복. 카드 효과 설명과 계산도 분리됨.

작업 범위: 기존 고딕 도감에 10분류, 검색·교차 필터, 상세 기록과 관련 항목 이동을 추가한다. 공통 GameData가 원본 JSON을 읽으며 효과 설명도 수치에서 생성한다. 실제 보유 카드의 강화/인챈트는 인스턴스에만 적용한다. 콘텐츠 수량 목표 전체의 완성을 뜻하지 않는다.

## 구현 결과
- `scripts/game_data.gd`: JSON 캐시, 효과 설명, 강화 계산. 전투·상점·보상·도감 모두 같은 카드를 읽는다. JSON 파일 변경은 다음 게임 실행부터 적용한다. 이미 획득해 강화/인챈트한 카드 인스턴스는 원본과 분리된다.
- 카드 10, 캐릭터 4, 유물 2, 몬스터 3개 변형(파수꾼 동일 아트), 포션/인챈트/이벤트 각 1, 파워 3. 기존 지역/스토리 유지.
- 등급·타입·캐릭터 복합 필터와 전체 기록 문자열 검색, 결과 없음 상태, 관련 항목 양방향 이동.
- 독립 카드 상세: 이미지, 비용, 캐릭터, 등급, 타입, 대상, 기본/강화 효과, 키워드, 획득처, 관련 기록. 유물 저주 여부와 몬스터 HP/행동/ACT/드랍 포함.
- 맹독, 출혈, 다음 공격 증폭을 전투에 연결. 휴식 강화, 제단 인챈트, 상점 회복약 즉시 복용/유물 구매를 실제 데이터에 연결.
- 새 벡터 심볼 4개는 프로젝트의 기존 고딕 SVG 스타일을 확장했다. 사이트 이미지·아이콘은 사용하지 않았다.

## Godot AI MCP 검증
실행 r101102-1, r249924-2. 모든 분류 첫 이미지 정상, 검색 1건/0건, 미라 필터 2건, 등급+타입 필터 1건. 관련 버튼으로 카드→맹독 파워 이동, 상세 스크롤 53px 확인.

출혈 카드 사용 후 적 HP 45→37, 턴 종료 후 34/출혈 2. 다음 공격 증폭 사용 후 적 HP 30/증폭 소모. 강화→인챈트 피해 6→9→12, 원본 6 유지. 회복약 HP 40→60/골드 200→165. 핏빛 계약서 최대 HP 110→93.

공유 카드 원본 피해를 검사 중 31로 바꾸자 상점·보상·도감 모두 31을 표시했다. 검사 후 원래 수치로 복구했다. 마지막 실행에서 스크립트 오류 없음. 스크린샷: `catalog-card.png`.

## 남은 범위
기존 전체 게임 목표인 12명/60유물/100이벤트/5ACT 및 미라의 나머지 독립 모션은 완성되지 않았다. 포션은 현재 상점에서 즉시 사용하는 회복약이며 보관 슬롯 시스템은 없다. 몬스터 3개는 동일 파수꾼의 난이도 변형이며 별도 신규 몬스터 아트가 아니다.
