# Codex 요청 — 휴식(야영지) 화면 도트 그림 (2차 수정본)

사용자 방향: **휴식 화면은 캐릭터와 불을 도트(픽셀)풍으로 귀엽게.** 그래서 휴식 화면(`scripts/rest_view.gd`)을 도트로 다시 만들었다. 지금은 코드가 그린 도트 배경(밤하늘·성당 아치 실루엣·돌바닥)과 4프레임 도트 모닥불, 기존 도트 SD 미라(`pixel_sd_plague_v3/idle`)를 쓰는 임시 구성이다. 참고: `docs/rest-scene-1440.png`

아래 그림이 오면 교체한다. 모두 **도트풍, 파일은 nearest 확대를 전제로 한 저해상도(그림 1개 = 도트 1칸이 4픽셀 정수배)**로 부탁한다.

## 1. 야영지 배경 — `assets/rest/campfire_scene_v1.png` (선택, 있으면 자동 사용)
- 360×225 도트 그림(또는 4배인 1440×900, 도트 칸이 정확히 4px). 글자·UI 없음.
- 무너진 성당 회랑의 밤. 보라·남색 하늘과 별, 고딕 아치 실루엣, 석재 바닥. 모닥불의 주황 빛이 바닥에 번지는 모습은 그려도 되지만 **모닥불 자체(장작·불꽃)는 비워 둘 것**(코드가 그린다. 위치는 도트 좌표 (240,150)).
- 왼쪽 중앙(x 70~190)은 캐릭터가 서고, 하단 중앙(y 178~218)은 버튼이 올라가므로 단순하게.

## 2. 도트 모닥불 스프라이트 (선택) — `assets/rest/campfire_pixel_v1.png`
- 불꽃 4프레임 가로 시트(프레임 28×40, 투명 배경) + 장작·돌 둘레 1장(64×24). 귀엽고 통통한 불꽃, 주황·노랑·붉은 3~4색 팔레트.
- 지금 코드가 그린 불꽃보다 개성이 있어야 의미가 있다(눈 달린 마스코트 불꽃까지는 원치 않고, 불똥이 튀는 정도).

## 3. 캐릭터 앉은 도트 (후순위) — `assets/characters/<id>/pixel_sd_*/rest_sit.png` (+ 졸기 2프레임)
- 모닥불 앞에 앉아 불을 쬐는 도트 SD. 미라는 약병을 만지작거리는 모습이면 좋다. 지금은 서 있는 idle을 쓴다.
- 미라 → 카리안 → 세라 → 루시안 순.

## 4. 선택지 도트 아이콘 (선택) — `assets/rest/icon_rest_v1.png`, `icon_upgrade_v1.png`
- 64×64 도트, 투명 배경. 휴식: 침낭 또는 김 나는 컵. 강화: 모루 위 카드 또는 망치.
