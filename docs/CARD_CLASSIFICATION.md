# 카드 소속과 등급 — 2026-10-02

참고: https://spire-codex.com/kor/cards 의 캐릭터·색상·유형·희귀도 분류. 디자인, 이미지, 아이콘과 팔레트는 복제하지 않는다.

## 두 개의 독립 축
- character=common: 무색 공용. 누구나 사용하는 카드이며 rarity=일반과 같은 뜻이 아니다. 무색 희귀·무색 전설도 같은 구조로 표현한다.
- character=캐릭터 ID: 캐릭터 전용. 외곽 프레임 색과 소속 문구로 구분한다.
- rarity: 일반/고급/희귀/영웅/전설. 중앙 타입 띠의 색과 글자로 구분한다. 강화 여부는 별도다.
- 기존 Content Tool 원본→catalog→GameData의 character/rarity를 그대로 사용한다. 별도 카드 수치나 소속 원본을 만들지 않는다.

## 적용
scripts/card_style.gd는 화면들이 공유할 색상/표시명 해석기다. 미라 녹청, 칼리안 적갈, 세라 보라, 루시안 탁금, 무색 은회색. 나머지 캐릭터 색은 향후 확장용 예약이며 플레이 가능 구현을 의미하지 않는다.
현재 BattleCard의 독립 고딕 프레임에 소속색을 적용하고 중앙 띠에 등급색을 적용했다. 그림과 효과 양피지는 원색을 유지한다. 잘못 고정되어 있던 '미라 전용' 문구도 실제 소속으로 표시한다.

## 남은 작업
Godot 4.7.2 실제 실행: CARD_SHAPE_QA 두 해상도와 소속/등급 독립성 실패0, MIRA_HAND_QA 실패0. 최신 화면 docs/card-hand-1440.png 및 card-hand-1280.png. 테스트의 OS 포인터 위치를 주입 좌표와 맞춰 hover 검사의 외부 입력 간섭을 해결했다.

도감·보상·상점의 세로 카드 UI 통일 및 색상 필터, 추가 무색 카드 콘텐츠/획득 밸런스는 후속이다. 현재 기본 공격/방어의 common 사용 자격은 유지하며, 이번 변경으로 전용 카드 풀을 섞거나 신규 카드 효과를 추가하지 않는다.
