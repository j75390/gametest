# 미라 타격 연출 — 2026-10-02

## 이번 구현
- 미라 한 명부터 적용. 기존 pixel_sd_v1 독립 12프레임/6모션을 그대로 사용한다.
- 기본 공격: 0.16초 준비 → 0.16초 돌진 → 명중 판정/섬광/피격 흔들림/피해 숫자 → 0.08초 접촉 유지 → 0.22초 복귀 → 0.18초 정리.
- 공격 스킬: 같은 명중 흐름에서 돌진 대신 보라색 주술/초록색 독 투사체. 방어는 제자리 푸른 파동.
- HP는 명중 콜백에서 한 번 변경하며 HP바와 요약 수치를 즉시 갱신한다. 에너지는 사용 시 한 번 소비하고 연출 중 카드/턴 종료/덱 버튼은 잠근다.
- 적 반격 시 미라 hurt/death 모션. 사망은 마지막 독립 프레임 재생 완료 후 실패 화면으로 전환. 적은 처치 시 페이드.
- 독/맹독은 개별 피해 내역을 반환하는 tick_details로 각 상태 이름/색/피해 숫자를 표시. 한 번만 계산하며 DOT 처치 시 반격을 생략한다.
- BattleFX는 연출만 담당하고 실제 효과는 main.gd에서 적용한다. 다른 세 캐릭터의 기존 그림과 처리 경로는 유지한다.
- 원정 실패 화면에 game_over 상태를 명시하여 보이지 않는 전투 입력이 살아 있던 문제도 수정.

## 참고 확인
사용자 제공 포켓몬 운빨던전.zip의 app.asar 내부 gameScreen.js/styles.css/mapScreen.js를 읽었다. 움츠림/돌진/복귀, 타격 섬광·색변화·피해 숫자, 지도 위 이벤트 창 구조를 참고했다. 원작 코드나 캐릭터/음원 자산은 게임에 복사하지 않았다. Godot Tween과 별도 효과 노드로 구현한다.

## 다음 작업 / 미완성
이번 범위는 미라 타격 모션. 전투 배경/완성형 카드 손패/드래그 대상 화살표/본체 hover 전체 능력/ACT 진입 이벤트는 아직 이번 변경에 포함하지 않았다. 타격 효과음·회피/치명타 게임 규칙·다른 캐릭터 전용 연출도 미구현.
