# 미라 독립 모션 프레임 교체 — 진행 중

2026-09-29 사용자가 첨부 시트를 자르는 방식을 거부하여 기존 Mira AtlasTexture 프레임을 전부 해제했다. 이전 MIRA_ASSET_PACK.md의 시트 좌표/31프레임 설명은 더 이상 적용되지 않는다.

image_gen으로 새로 제작한 투명 SD 원화는 assets/characters/mira/animated/idle.png와 blink.png 두 장이다. 원본 생성 결과는 Codex generated_images 폴더에 보존했다. 첨부 전신 원화는 디자인 참고로 사용했으며 이미지를 잘라 모션으로 만들지 않았다.

기본 자세 2.8초, 눈 감기 0.14초로 재생한다. 독립 이미지 전체를 읽고 원본 비율을 보존한다. 전투와 도감이 같은 데이터와 프레임별 재생 시간을 사용한다.

이동/공격/스킬/피격/사망의 새 자세 생성은 이미지 도구의 usage_limit_reached (429)로 중단되었다. 이 모션들은 미완성이다. 도감 버튼에 제작 중 상태를 표시하고 비활성화했다. 전투는 해당 자세가 없으면 새 기본 원화를 표시하여 이미지가 사라지지 않게 한다. 이것을 완성된 행동 애니메이션으로 간주하지 않는다.

Godot AI MCP 실제 실행에서 도감 기본 이미지가 AtlasTexture가 아닌 CompressedTexture2D임을 확인했다. 새 프레임 표시, 눈 감기 전환, 일시정지, 미제작 상태 표시를 검사했다. 전투 표시도 새 독립 원화를 사용한다. 검사 도중 start_battle 인자를 누락한 QA 호출 1회는 수정했다.

다음 작업: 동일 디자인의 이동 좌우 발 디딤, 공격 준비/발사/회수, 스킬 집중/방출, 피격/회복, 쓰러짐/사망 자세를 개별 투명 이미지로 생성하고 프레임 크기·발 위치·타이밍을 실제 실행에서 재검수한다.
