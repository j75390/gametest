# 미라 손패·조준·상태 설명 — 2026-10-02

## 적용
- 미라 손패에 기존 아트/비용/이름/타입/등급/실제 효과 문구를 카드 프레임으로 묶었다. 마우스 hover 확대, 에너지 부족 시 어둡게 표시.
- 적 대상 카드: 드래그하여 적 위에서 놓거나, 카드 클릭 후 적 클릭. 곡선 화살표와 유효 대상 금색 모서리 표시. 대상 밖 드롭/우클릭/ESC는 취소하며 에너지와 손패 보존.
- 자신 대상 방어 카드: 클릭 또는 손패 위로 드래그. 적을 고르지 않는다. 실제 효과는 기존 play_card→명중 연출/콜백으로 연결.
- 조준 확정 후 입력은 잠기며 중복 사용 방지. 카드 사용 후 설명 줄바꿈의 최소 높이가 늦게 갱신되던 문제를 minimum_size_changed 재배치로 수정.
- 미라/적 본체 hover는 현재 HP와 상태 전체. 몬스터는 등록된 능력 설명과 다음 행동 포함. 상태 아이콘 hover는 그 상태만, 다음 행동 문구 hover는 피해량/부여 상태. 존재하지 않는 미라 전용 패시브를 만들어 표시하지 않는다.
- 툴팁은 기존 공통 Power/Status 데이터를 사용한다. 폭 제한/자동 줄바꿈/고딕 색상 패널. HP바 색상도 식별 가능하게 변경.
- 미라 타격 숫자의 fade 종료까지 기다린 뒤 화면 갱신하여 숫자 중간 끊김 해결.

## 검사
최종 결과: MIRA_HAND_QA / MIRA_HIT_QA / MIRA_MOTION_QA / POISON_SPLIT_QA 모두 failures=0. 손패 입력과 독·맹독 검사는 바탕화면 실제 프로젝트에서도 통과. 바탕화면 변경 파일은 이전 Git HEAD와 비교·백업 후 병합했다. 백업은 PC 로컬 work/before-mira-hand-desktop.zip.
MIRA_HAND_QA: 실제 마우스 press/move/release로 드래그/클릭 대상 선택/잘못된 드롭/우클릭/ESC/방어/에너지 부족 검사. 1440×900 버튼 화면 내 표시, 본체·아이콘·행동 툴팁 내용 검사. 실제 본체 hover 팝업 캡처 docs/mira-hand-tooltip.png.
MIRA_HIT_QA 보강: 창 크기 변경/반복 입력/방어 카드/완전 방어. 원래 타격·사망·DOT 테스트 유지.

## 범위
미라 우선. 다른 캐릭터의 기존 전투 UI는 보존. 적 하나 대상만 현재 전투에서 지원하며 다중 적 조준은 아직 미구현. 전용 능력 표시에는 실제 등록 데이터가 필요하다.
카드 프레임과 조준 조작을 연결한 단계이며 신규 주요 카드 일러스트나 배경은 생성하지 않았다. ACT 인물 선택 이벤트, 완성형 전투 배경, 효과음, 나머지 캐릭터 전용 연출은 다음 작업이다.
