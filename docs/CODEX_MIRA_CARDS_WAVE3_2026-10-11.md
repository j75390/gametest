# Codex 요청 — 미라 카드 3차 일러스트 19장

> **범위: 미라만.** 다른 캐릭터는 미라가 완성된 뒤에 요청한다.

미라 카드 3차 19장이 게임에 들어갔다(효과 테스트 통과, `tools/mira_wave3_qa.gd`). 지금은 승인된 기존 미라 카드 그림을 **임시로 돌려 쓰는 중**이라 같은 그림이 반복된다. 카드마다 고유한 그림이 필요하다.

## 규칙 (v2와 동일)
- 프레임·글자·숫자·마나 표시 없음. 카드 일러스트 영역에 맞는 구도로 한 장씩 단독 제작.
- 기존 승인 미라 카드(v2)와 같은 화풍·색조(검보라 + 약품 색 포인트). 몬스터 때처럼 실사풍으로 가지 말 것.
- **효과가 한눈에 읽히는 구도.** 얼굴 클로즈업·손 내미는 포즈만 반복하지 말고 도구·약병·현상·장면을 중심으로.
- 미라가 나올 때는 현재 디자인(옆 까마귀 가면, 상아 소매, 검정 긴 치마) 유지. 안 나와도 되는 카드는 도구·현상 중심으로.
- 납품: `assets/delivery/claude_20261011/cards_wave3/<id>_v3.png` + `manual_review.json`(verdict). 통과분만 Claude가 적용한다.
