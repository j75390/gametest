# 원정 지도 이미지 교체

사용자 수정 요청에 따라 벡터 양피지 배경을 새로 생성한 실제 래스터 일러스트로 교체했다. 내장 image_gen 도구 사용. 원본은 Codex generated_images에 보존했고 프로젝트 자산은 `assets/map/expedition-parchment-v2.png`다.

배경 그림에는 경로·노드·문자·UI가 없다. 경로는 게임에서 생성하는 점선, 노드는 아이콘과 이름을 가진 실제 원형 버튼, 안개는 별도 레이어로 그린다. 현재 위치/이동 제한/2칸 공개/유물 규칙은 유지한다.
