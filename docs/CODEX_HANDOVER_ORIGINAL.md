# 운빨원정대 Codex 인수인계

이 문서는 ChatGPT와 사용자가 지금까지 합의한 게임 방향을 Codex에 주입하기 위한 기준 문서다.
단순 참고가 아니라 현재 프로젝트의 작업 기준으로 사용한다.

## 1. 게임 방향
- 다크 고딕 판타지 덱빌딩 로그라이크 RPG
- 싱글 + 친구 중심 멀티
- Slay the Spire / Spire Codex: 카드·유물·이벤트·파워·도감 구조 참고
- Chrono Ark: 캐릭터 선택 UI 사용성 참고
- 명일방주 로그라이크: 조건부 이벤트, 특수 전투, 파티 이벤트 참고
- Lobotomy Corporation: 유물 기록문의 짧고 불길한 톤 참고
- 참고작 디자인/이미지/아이콘을 그대로 복제하지 말 것

## 2. 작업 원칙
- 계획만 세우지 말고 실제 Godot 프로젝트에 하나씩 구현
- 코드 작성 → 실행 → 확인 → 수정 → 재실행 → 완료
- placeholder/가짜 UI/크롭 이미지로 완료 처리 금지
- 없는 기능/에셋은 미완성으로 표시
- Godot AI MCP로 실제 실행 확인 후 완료 보고
- 작업 후 인수인계/작업로그 갱신

## 3. 캐릭터
우선:
- 미라
- 칼리안
- 세라
- 루시안

추가:
- 레온하르트
- 에리샤
- 모르간
- 카인
- 벨라
- 아이작
- 실비아
- 드레이크

전투 테마:
- 미라: 독 / 연금술 / 흡수 / 저주
- 칼리안: 참격 / 출혈 / 연속 공격
- 세라: 마나 / 저주 / 광역 마법
- 루시안: 회복 / 축복 / 신성 심판
- 레온하르트: 방어 / 도발 / 반격
- 에리샤: 회피 / 치명타 / 표식
- 모르간: 저주 / 약화 / 인형
- 카인: 탄약 / 건블레이드 / 콤보
- 벨라: HP 희생 / 흡혈
- 아이작: 포탑 / 폭탄 / 기계
- 실비아: 빙결 / 둔화 / 제어
- 드레이크: 광폭화 / HP 비례 공격

캐릭터별 카드 풀은 서로 다르게 유지.

## 4. 캐릭터 선택 화면
- 왼쪽: 캐릭터 portrait 목록
- 중앙: 선택 캐릭터 큰 전신 일러스트
- 오른쪽: 이름 / 클래스 / HP / 특징 / 패시브 / 전투 스타일 / 시작 유물 / 시작 덱
- 하단: 돌아가기 / 상세정보 / 도감 / 원정 시작
- 멀티: 파티 슬롯 표시
- 캐릭터 선택용 이미지는 별도 전신 자산 사용
- 배경 포함 완성 일러스트를 UI 배경에 억지로 중첩하지 말 것

## 5. 이미지 제작
절대 규칙:
- 종합 시트에서 잘라 쓰지 않는다
- 전신 / SD / 도트 / 카드아트 독립 제작

고품질 우선:
- 캐릭터 전신
- 캐릭터 선택 일러스트
- 주요 카드 아트
- 보스 대표 일러스트
- 중요 이벤트 CG
- ACT 대표 배경
- 고대 유물 스토리 아트

ComfyUI 우선:
- 일반/고급/희귀 유물 아이콘
- 포션
- 인챈트 아이콘
- 파워/상태이상 아이콘
- 소품/보조 자산

자산 상태:
draft / generated / needs_review / approved / rejected
approved만 최종 적용.

- 카드

## 7. 카드
기본 시작 덱:
- 기본 공격
- 기본 방어

전투 보상:
- 3장 중 1장 선택
- 건너뛰기 가능

카드 등급:
- 일반 / 고급 / 희귀 / 영웅 / 전설

필수 데이터:
id / name / character / energy_cost / rarity / type / target /
description / upgraded_description / keywords / image / enchantable

화면 필수:
- 카드 이미지
- 에너지 비용
- 카드명
- 등급
- 타입
- 실제 효과 설명

도감/전투/상점/보상은 같은 원본 데이터를 사용.

## 8. 인챈트
카드에 추가 효과 부여.
예: 흡혈 / 연쇄 / 절약 / 저주 / 출혈 강화 / 독 확산 / 방어 전환

## 9. 파워/상태이상
분류:
BUFF / DEBUFF / POWER / CURSE / SPECIAL

중첩:
SINGLE / COUNTER / DURATION / CONDITIONAL

플레이어와 몬스터 모두 동일한 시스템 사용.
일반 몬스터 / 엘리트 / 보스도 동일.

UI:
- HP바 아래 상태 아이콘
- 중첩 수 표시
- 남은 턴 표시
- hover 툴팁

툴팁:
- 이름
- 분류
- 중첩
- 남은 턴
- 정확한 효과 설명

## 10. 맵
- ACT 시작 시 전체 분기형 맵 랜덤 생성
- 현재 위치 + 앞으로 약 2칸만 공개
- 이후는 노드와 길 자체가 안개로 숨김
- 이동 시 새 위치 기준 다음 2칸 공개
- 지나온 길 유지
- '탐험가의 지도' 보유 시 현재 ACT 전체 공개
- 멀티에서 한 명만 지도 보유해도 전원 맵 공개

## 11. 유물
수량:
- 일반 60
- 고급 40
- 희귀 25
- 영웅 12
- 전설 5
- 고대 12
총 154개

성격:
- 좋은 유물
- 애매한 유물
- 특정 빌드 전용
- 조건부
- 양날의 검
- 저주 유물
- 파티 공용 유물

효과 범위:
PERSONAL / PARTY / GLOBAL_MAP

좋은 유물만 만들지 않는다.

## 12. 고대 유물
- 캐릭터당 1개, 총 12개
- 일반 드랍 금지
- 상점 금지
- 일반 보스 보상 금지
- 캐릭터 전용 초희귀 특수 이벤트 체인 최종 보상
- 캐릭터 서사 보상 역할

## 13. 유물 기록문
짧고 의미심장한 관찰/기록문 톤.
효과 + 기록 + 획득 이벤트 + 필요 시 숨겨진 추가 기록.

## 14. 이벤트
목표:
- 일반 이벤트 100개 이상
- 캐릭터 전용 이벤트 캐릭터당 6개

일반:
- 2~4문장 상황 설명
- 선택지 2~4개
- HP / 최대 HP / 골드 / 카드 / 유물 / 포션 / 저주 / 인챈트 / 특수전투 다양화

연속:
- Stage 1 → 2 → 3...
- 진행할수록 위험/보상 증가
- 중간 이탈 가능
- 조건부 선택지 가능

## 15. 캐릭터 전용 이벤트
캐릭터당 6개:
- 일반 전용 3
- 조건부 전용 2
- 초희귀 연속 이벤트 1

싱글:
현재 캐릭터 전용 이벤트 중 랜덤.

멀티:
캐릭터 이벤트 판정 시 각 플레이어가 자기 캐릭터 전용 이벤트를 따로 진행.
개인 결과가 기본.

## 16. 멀티 파티 이벤트
- 모든 플레이어 같은 이벤트/선택지
- 각자 비밀 투표
- 전원 완료 후 공개
- 최다 득표 채택

동률:
- 동률 선택에 투표한 플레이어 얼굴 아이콘 사이를 빛이 이동
- 빠르게 돌다가 점점 느려짐
- 한 명 얼굴에서 정지
- 그 플레이어가 고른 선택지 최종 채택

## 17. 이벤트 텍스트 연출
EventTextEffect:
NORMAL / SHAKE / STRONG_SHAKE / WAVE / PULSE /
FADE / TYPEWRITER / PAUSE / COLOR

모든 문장에 남발 금지.
공포/충격/환청/저주/거대한 존재 등장에 제한적으로 사용.

## 18. 상점
판매 기능 없음.
판매:
- 카드
- 유물
- 포션
- 카드 제거

카드 제거:
- 상점 방문당 1회
- 가격 상승 가능: 75 → 100 → 125...

일부 저주/봉인/운명 카드는 일반 상점 제거 불가.

## 19. 도감
카테고리:
캐릭터 / 카드 / 유물 / 몬스터 / 포션 / 마법부여 /
이벤트 / 파워 / 저주 / 지역

미등록:
- 실루엣만
- 이름 없음
- 정보 없음
- 툴팁 없음
- 클릭 반응 없음
- '클릭 불가' 같은 문구도 없음

등록:
- 실제 이미지
- 클릭 가능
- 상세정보

완성률:
- 전체 완성률
- 카테고리별 수집률

패배해도 이미 등록된 정보는 유지.

## 20. 몬스터
목표:
- 일반 몬스터 30+
- 엘리트 10+
- 보스 6+
- ACT 5+

몬스터도 HP바 아래 버프/디버프/파워 아이콘 표시.
hover 툴팁 사용.
