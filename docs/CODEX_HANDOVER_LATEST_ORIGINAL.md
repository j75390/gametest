# 운빨원정대 — 최신 Codex 인수인계

이 문서는 ChatGPT와 사용자가 지금까지 합의한 **최신 프로젝트 기준**이다.
Codex는 이 문서를 단순 참고가 아니라 현재 프로젝트의 작업 기준으로 사용한다.

---

# 1. 프로젝트 방향

장르:
- 다크 고딕 판타지
- 덱빌딩 로그라이크 RPG
- 싱글 + 친구 중심 멀티

참고 방향:
- Slay the Spire / Spire Codex: 카드, 유물, 이벤트, 파워, 도감 구조
- Chrono Ark: 캐릭터 선택 UI 사용성
- 명일방주 로그라이크: 조건부 이벤트 / 파티 이벤트
- Lobotomy Corporation: 짧고 불길한 기록문 톤
- Reddit/Pinterest/기타 게임 아이콘은 아이콘 가독성/분류 참고용

중요:
- 참고 디자인/아이콘/텍스트를 그대로 복제하지 않는다.
- 전체 비주얼은 오리지널 다크 고딕 판타지 스타일 유지.

# 3. 캐릭터

현재 기준 12명:
- 미라: 독 / 연금술 / 흡수 / 저주
- 칼리안: 참격 / 출혈 / 연속 공격
- 세라: 마나 / 저주 / 광역 마법
- 루시안: 회복 / 축복 / 신성 심판
- 레온하르트: 방어 / 도발 / 반격
- 에리샤: 회피 / 치명타 / 표식
- 모르간: 저주 / 약화 / 인형
- 카인: 탄약 / 건블레이드 / 콤보
- 벨라: HP 희생 / 흡혈
- 아이작: 포탑 / 폭탄 / 기계
- 실비아: 빙결 / 둔화 / 제어
- 드레이크: 광폭화 / HP 비례 피해

캐릭터별 전용 카드 풀은 서로 다르게 유지한다.

# 4. 캐릭터 자산 제작 규칙

절대 금지:
- 종합 시트에서 잘라서 SD/도트/카드아트 대용 사용
- 임시 이미지 크롭으로 최종 자산 처리
- UI 스크린샷 위에 투명 클릭 영역만 씌우기

캐릭터 1명당:
- 전신 일러스트 2장 이상
- portrait
- SD/chibi 다수
- 실제 도트/전투 행동 스프라이트
- 카드아트 다수

중요:
- 캐릭터 선택 화면의 전신 아트는 별도 자산
- 도감/전투/카드에서 같은 캐릭터처럼 보이도록 스타일 통일

# 6. 아이콘 스타일 방향

참고:
- Pinterest 다크 판타지 아이콘 보드
- Remnant 계열 상태 아이콘 가독성
- Spire Codex의 Power 분류/표현 방식

운빨원정대 기본 스타일:
- 1:1 정사각형
- 중앙 오브젝트 1개
- 작은 크기에서도 구분 가능한 강한 실루엣
- 검정 / 진홍 / 보라 / 금색 / 청록 계열
- 글자 없음
- 워터마크 없음
- 32~64px에서도 알아볼 수 있게 단순화
- 유물은 재질감/장식 강조
- 상태이상/파워는 유물보다 더 단순하게

색 방향:
- 버프: 청색 / 청록 / 금색
- 디버프: 붉은색 / 암적색
- 독: 초록/보라
- 화상: 주황/적색
- 출혈: 진홍
- 감전: 노랑/청색
- 빙결: 백청/하늘색
- 저주: 보라/검정
- 캐릭터 고유 파워: 캐릭터 테마색

ComfyUI 공통 아이콘 프롬프트 방향:
dark gothic fantasy game icon,
single centered object,
strong readable silhouette,
hand-painted RPG inventory/status icon,
aged blackened metal / bone / antique gold,
subtle crimson or violet magical glow,
dark simple background,
high contrast,
readable at 64px,
no text, no letters, no watermark,
1:1 composition

# 10. 파워 / 상태이상 시스템

Spire Codex의 Power 구조를 참고하되 오리지널 효과로 설계.

큰 분류:
- BUFF
- DEBUFF
- POWER
- CURSE
- SPECIAL

중첩 방식:
- SINGLE
- COUNTER
- DURATION
- CONDITIONAL
- 필요 시 NONE 추가 가능

예:
- 출혈: DEBUFF + COUNTER
- 취약: DEBUFF + DURATION
- 바리케이드류: POWER + SINGLE
- HP 50% 이하 공격 증가: POWER + CONDITIONAL

파워는 단순 수치 변화뿐 아니라:
- 지속 규칙 변경
- 트리거형
- 조건형
- 반응형
- 변환형
- 룰 변경형
을 포함한다.

현재 1차 초안:
- 총 300개

구성:
- 공용 버프 35
- 공용 디버프 35
- DOT/CC 상태 25
- 공용 Power 55
- 저주/특수 25
- 캐릭터 전용 Power 96 (12명 × 8)
- 몬스터/엘리트/보스 전용 29

300개 목록은 별도 TXT 사용.

# 11. 파워/상태이상 UI

플레이어와 몬스터 모두 동일한 공통 시스템 사용.

대상:
- 플레이어
- 일반 몬스터
- 엘리트
- 보스

표시:
- HP바 아래 상태 아이콘
- 중첩 수
- 남은 턴
- 여러 개일 경우 좌→우 정렬
- 너무 많으면 줄바꿈 또는 +N 축약 가능

Hover 툴팁:
- 이름
- 분류
- 현재 중첩
- 남은 턴
- 정확한 효과 설명

예:
맹독
디버프 · 5중첩
턴 시작 시 현재 맹독 중첩 수만큼 피해를 받습니다.

중요:
플레이어용과 몬스터용을 따로 만들지 않는다.
`UnitStatusSystem` 같은 공통 구조 사용.

# 12. 맵

ACT 시작 시 전체 맵은 내부적으로 생성.

기본 시야:
- 현재 위치
- 앞으로 약 2칸/2줄 공개
- 그 이후 노드/길은 보이지 않음
- 이동할 때마다 다음 2칸 공개
- 지나온 길은 유지

유물:
- 탐험가의 지도
- 현재 ACT 전체 맵 공개

멀티:
- 파티원 한 명만 보유해도 모두 전체 맵 공개

# 15. 고대 유물

- 총 12개

- 상점 금지
- 일반 보스 보상 금지

# 19. 멀티 파티 이벤트

모든 플레이어:
- 같은 스토리
- 같은 선택지

진행:
1. 각자 비밀 투표
2. 선택 중에는 선택 내용 숨김
3. 전원 완료 후 득표 공개
4. 최다 득표 선택지 실행

동률:
- 동률 선택지에 투표한 플레이어 얼굴 아이콘을 대상으로 룰렛
- 빛이 얼굴 사이를 빠르게 이동
- 점점 느려짐
- 한 명에서 정지
- 그 플레이어가 투표한 선택지가 최종 선택

파티 이벤트 결과:
- 전원 HP
- 파티 골드
- 특수 전투
- 공용 유물
- 다음 맵 변경
- 확률 변화 등

# 25. 현재 Content Tool 역할

- 사람이 직접 GUI 입력
- Codex가 API/CLI 자동 입력
- ComfyUI 반복형 자산 호출
- JSON 저장
- 검증
- Godot Export
- 인수인계 자동 생성

기획 → 데이터 생성 → ComfyUI 호출 → 검수 상태 기록 → Godot Export

중요:
핵심 일러스트는 ComfyUI 자동 확정 금지.
