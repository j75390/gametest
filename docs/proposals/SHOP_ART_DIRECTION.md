# 성당 행상 상점 — 제작 및 Claude 통합 제안

2026-10-08 사용자 요청: 상점은 최대한 고품질로 제작. Claude 작업6/7 최신 기록을 확인했다. 아직 상점 별도 명세나 담당 코드 착수 기록은 없어 Codex는 독립 그림과 배치 제안을 만든다.

## 현재 기능과 일치하는 표시
현재 main.gd show_shop: 카드60G, 유물90G, 포션 각 데이터 가격(즉시 복용), 카드 제거75G. 판매 기능은 없다. 가격과 구매 제한을 그림에 굽지 않는다. 상인에게 새 서사·보상·이름을 임의로 부여하지 않는다.

## 화면 구성 제안 (1440×900)
- 공용 상단 바 영역0~76 유지. 상점 배경은 아래 분위기 담당이며 HUD와 상품은 실제 UI 노드.
- 왼쪽 약300px: 익명 상인. 중앙·오른쪽은 상품. 배경의 장식보다 카드·가격·버튼 대비 우선.
- 카드/유물/포션/서비스 중 선택한 분류만 크게 표시. 기존 승인 카드 컴포넌트를 재사용하고 카드 그림을 별도 사각 사진으로 나열하지 않는다.
- 유물/포션은 빈 진열판에 독립 그림을 표시. 이름·효과·가격은 읽기 쉬운 명조/본문 글꼴로 구분. 즉시복용 문구 유지.
- 오른쪽 아래 상점 나가기. 골드 부족/구매완료/제거 불가 상태는 실제 데이터로 처리. 장식에 클릭영역만 올리지 않는다.
- 1280×720에서는 상품 영역 스크롤 또는 간격 축소. 상품·버튼이 화면 밖으로 밀리지 않게 한다.

## 담당
Codex: assets/ui/shop 신규 그림, 생성 프롬프트·검수·제안 문서. Claude: scripts 상점 구조/실제 구매·상단 바 재사용/1280·1440 실행 QA/바탕화면 반영. 기존 승인 미라/카드/전투 UI는 유지. 포션 인벤토리 등 미구현 기능은 추가하지 않는다.

그림 완성과 실제 상점 구현은 별개다. shop_composition_review.png는 독립 자산 배치 검토이며 게임 화면 캡처가 아니다.
