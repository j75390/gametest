# 미라 의상·팔레트 기준 고정

권위 기준: 사용자가 2026-10-11 제공한 미라 원정 시작 화면 일러스트(clipboard-856559c1). 기존 보라색 SD 디자인보다 이 기준을 우선한다.

- 검정에 가까운 가지색 머리. 보라 반사는 약하게, 꽃·자홍색 술 장식 반복 제거.
- 머리 옆 상아색 까마귀 부리 가면, 탁한 금속 테두리. 얼굴에 쓰거나 후드로 대체하지 않음.
- 어깨와 가슴을 덮는 상아색 블라우스, 검정 높은 목깃, 넓은 상아색 소매.
- 검정 허리 코르셋과 긴 검정 치마. 노출된 허벅지/가터/비키니형 상의 제거.
- 검정 장갑·부츠, 낡은 황동 장식, 허리띠의 작은 보라 약병 2개.
- 보라색은 약과 효과에 집중. 카드 효과의 독 초록/정화 청록 등 기능 색은 유지.

## 현재 작업 범위
Codex는 자산 및 제안문서만 작성. 기존 canonical, character_assets.json, scripts, 실행 복사본 적용은 Claude 담당.
새 SD 기본 자세는 기존 자세를 수정한 독립 투명 이미지. 도트는 이를 축소 대체하지 않고 픽셀 구도를 독립 생성한다.
카드는 의상이 크게 보이는 기본 타격/수비/구속 및 v2 대신 앓기/옮겨진 고통을 수정한다. 기존 독주입·맹독의 상아 소매/가면과 사물 중심 카드의 효과 구도는 보존한다.
소매의 옅은 보라 음영은 환경 반사광으로 허용하되 천 자체는 상아색이어야 한다.
