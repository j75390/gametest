# 미라 카드 v2 — 사용자 지적 반영

기존 신규 38장 v1의 합격을 철회했다. 얼굴 중심 반복 구도와 팔 연결 검수 누락 때문에 사용하지 않는다. 이전 자산은 ai/claude_mira_cards_20261011/withdrawn_portrait_v1에 보존했다.

## 제작 기준
- 효과와 실제 도구가 먼저 읽히는 장면: 약병 충돌, 메스, 바늘, 증류기, 증기, 붕대, 의식.
- 큰 얼굴 초상화 반복 금지. 인물이 필요한 장면도 효과가 주역이며 인물은 작게 배치.
- 명확한 외곽선, 넓은 색면, 제한된 명암. 160px 축소에서도 행동과 물건을 식별할 수 있어야 한다.
- 손가락 수뿐 아니라 소매→팔→손목 연결, 물건을 잡는 접촉을 확인한다. 복잡한 전신 포즈로 오류를 숨기지 않는다.
- 글자, 테두리, UI는 일러스트에 포함하지 않는다. 검수하지 않은 이미지를 합격으로 내보내지 않는다.

## 현재 인계
flask_barrage_v2: 단일 손과 세 약병의 투척/독액 충돌 구도로 교체하여 육안 검수.
나머지는 현재 v2 미완성. 기존 38장 전체가 다시 합격했다는 뜻이 아니다.
통과 경로는 CLAUDE_MIRA_CARD_MAPPING_20261011.json의 현재 v2 항목만 사용한다.
