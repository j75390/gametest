# 미라 하체 수정 후보 — 2026-10-08

기존 v2의 하체 연결과 신발 형태 검수를 놓쳤다. 신규 독립 투명 프레임 12장을 pixel_sd_plague_v3에 보존했다. 아직 실행 프로젝트에 연결하지 않았다.

## 육안 검수
- idle / idle_blink: 양쪽 허벅지·무릎·종아리·부츠가 분리되어 보인다. 동일 서 있는 자세로 비교했다.
- 공격 / 스킬 / 피격: 두 발과 관절 방향을 시트에서 확인했다. 공격 방출은 낮은 자세이므로 전체 높이를 idle과 강제로 같게 늘리지 않는다.
- death_fall / death_rest: 무릎을 꿇는 자세와 옆으로 쓰러진 자세를 별도 생성했다.
- **walk_b 보류**: 새 결과의 긴 앞치마형 옷이 다른 프레임과 다르다. 이 프레임은 통합하지 않는다. 12장 생성과 12장 최종 승인은 다르다.
- 독립 생성 프레임의 몸 중심·발 기준선·실제 크기가 다르다. 애니메이션 연결 전에 프레임별 정렬 및 실제 전투 크기 재검수가 필요하다. 현재 시트는 육안 후보 검토이며 실행 QA가 아니다.

1. v2 보존. 우선 idle / idle_blink 두 장을 비교하고 사용자 캡처와 같은 1440×900 전투에서 하체 확대 확인.
2. 승인 프레임에만 발 기준선과 몸 중심을 맞춰 character_assets.json에 등록. walk_b는 기존 파일로 섞지 말고 제외 상태 유지.
