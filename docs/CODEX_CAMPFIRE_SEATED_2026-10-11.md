# Codex 요청 — 모닥불 휴식 화면: 앉아서 쉬는 캐릭터 + 야영지 배경 (최우선)

> **범위: 미라만.** 사용자 방침: 미라를 완벽하게 끝낸 뒤에 다른 캐릭터(카리안·세라·루시안)를 만든다. 다른 3명은 지금 만들지 말 것.

## 사용자 지적
"누가 저렇게 일어나서 쉬냐. 슬레이 더 스파이어 2처럼 봐봐." 휴식 화면은 **캐릭터가 모닥불 곁에 앉아 쉬는 장면**이어야 한다. 프로젝트와 Codex 작업 폴더를 모두 찾아봤지만 쓸 만한 그림이 없다.
- 있는 것: `mira_seated_plague_v3.png`(상자에 걸터앉은 일러스트, 모닥불 장면 아님·성인 비율 일러스트), `death_rest.png`(쓰러진 도트).
- 없는 것: 불 앞에 앉은 모습, 야영지 배경.

## 화풍 (사용자: "도트 느낌으로 하든가, 아니면 제대로")
- **기본안(권장): 전투와 같은 손그림 SD(`pixel_sd_plague_v3`, `mira_sd_idle_v4` 화풍)**. 야영지 배경도 전투 배경(폐허 성당)과 같은 일러스트 화풍.
- 도트로 만든다면 배경·불·캐릭터 전부 도트로 통일. 일러스트 캐릭터를 도트 배경에 섞지 말 것.

## 필요한 그림
1. **야영지 배경 1장** `rest/campfire_bg_v1.png` 1440×900. 폐허 성당의 밤, 보라·남색 톤, 중앙 우측에 모닥불 자리(불 자체는 비움: 코드가 애니메이션 불을 올림. 불 중심 좌표 약 (960, 610)). 바닥에 번질 주황빛 반사는 그려도 됨. 하단 중앙(y 700~870)은 선택 패널이 올라가므로 단순하게.
2. **앉은 미라 1명** `rest/mira_sit_v1.png` 투명 배경 PNG, 불이 오른쪽에 있다고 가정하고 **불 쪽을 향해 바닥/통나무에 앉아 쉬는 자세**(무릎 안기, 손 쬐기, 약병 만지작 등). 의상·머리는 미라 현재 SD와 동일(새 가면 장식 포함).
3. 가능하면 **졸기/숨쉬기 변형 1장**(`mira_sit_v1_b.png`): 눈 감음 또는 어깨 오르내림. 코드가 2장을 번갈아 보여 준다.
4. 모닥불은 코드(애니메이션 불꽃)가 올리지만, **더 좋은 불꽃 시트가 있으면** 4프레임 가로 시트 `rest/fire_sheet_v1.png`(프레임 256×320, 투명)도 환영.

## 우선순위
배경 → 미라 앉은 그림 → 졸기 변형 → 불꽃 시트. (다른 캐릭터는 미라 완성 후 별도 요청)
