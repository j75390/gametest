# 미술 레퍼런스

이 폴더에 미술 방향을 참고할 원본 이미지를 보관한다.

references 폴더의 이미지는 미술 방향 참고용이다. 절대 잘라서 게임 자산으로 재사용하지 말고, 새 독립 자산을 제작할 때 스타일 가이드로만 사용한다.

사용자 제공 `C:/Users/DW/Desktop/포켓몬 운빨던전.zip`은 레이아웃과 사용성 참고 자료다. 실행 패키지의 도감 목록·스크롤 구조만 확인했으며 게임 파일을 이 프로젝트에 복사하지 않았다.

포켓몬의 캐릭터명, 이미지, 색상, 아이콘, 로고, 폰트, 디자인은 복제하지 않는다. 좌측 목록 / 중앙 원화 / 우측 정보 / 하단 모션·카드 / 상단 5개 탭 구조를 운빨 원정대 고유의 다크 고딕 스타일로 구현한다.

게임 도감 자산은 `assets/characters/`, `assets/monsters/`, `assets/cards/`의 프로젝트 전용 이미지로만 구성한다.
