# 잿빛 원정대 - Godot 4 프로젝트

학원/집 작업을 이어갈 때는 [동기화 안내](docs/PC_SYNC.md), [제작 인수인계](HANDOFF.md), [프로젝트 규칙](AGENTS.md)을 먼저 읽으세요. 기존 집 프로젝트에 덮어쓰지 말고 별도 clone 후 비교·병합하세요.

## 여는 방법
1. Godot 4.x 실행
2. Project Manager → Import
3. 이 폴더 안의 `project.godot` 선택
4. Import & Edit
5. F6/F5 또는 우측 상단 ▶ 실행

## 현재 들어간 기능
- 메인 메뉴
- 캐릭터 선택
- 캐릭터별 전용 카드 풀 구조
- 기본 공격/방어 스타터 덱
- 에너지 기반 손패 전투
- 드로우 / 버림 / 재셔플
- 전투 승리 후 카드 선택 보상 또는 스킵 (현재 캐릭터 전용 풀 2종으로, 3종 보상 목표는 미달)
- 랜덤 분기 맵 골격
- 앞으로 2칸씩 공개되는 안개 맵
- 탐험가의 지도 유물 획득 시 전체 맵 공개
- 상점: 카드 구매 / 카드 제거 1회
- 이벤트 / 휴식 / 보물
- 도감 / 설정 / 멀티 화면 골격

## 중요
이 프로젝트는 'Godot에서 바로 열리고 실행되는 기반 프로젝트'입니다.
캐릭터/카드/몬스터의 고퀄 독립 아트는 기존 레퍼런스와 분리해서 연결해야 합니다.
저품질 임시 캐릭터 그림이나 잘라낸 합성 이미지는 넣지 않았습니다.
