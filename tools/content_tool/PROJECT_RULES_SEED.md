# Codex에게 함께 넘길 기준

- 카드 / 유물 / 포션 / 인챈트 / 파워 / 몬스터 / 이벤트는 이 툴로 데이터 생성 가능
- 파워/상태이상은 플레이어와 몬스터가 동일한 시스템 사용
- 상태 아이콘은 HP바 아래, hover 툴팁
- 유물 수량: 일반 60 / 고급 40 / 희귀 25 / 영웅 12 / 전설 5 / 고대 12
- 고대 유물은 캐릭터당 1개, 특수 이벤트 체인에서만 획득
- 일반 이벤트 100+ / 캐릭터 전용 이벤트 캐릭터당 6개
- 멀티 파티 이벤트는 비밀 투표, 동률이면 얼굴 아이콘 룰렛
- 도감 미등록 항목은 실루엣만, 정보/툴팁/클릭 반응 없음
- 맵은 현재 기준 약 2칸만 공개하는 Fog of War
- 한 명이 탐험가의 지도 보유 시 멀티 전체 맵 공개
- 종합 이미지 시트 크롭 재사용 금지
- 반복형 아이콘/소품은 ComfyUI 우선, 중요 일러스트는 고품질 경로
